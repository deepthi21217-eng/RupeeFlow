# RupeeFlow – Unified Banking Intelligence & Financial Security Platform

### Smart Banking. Better Insights. Safer Transactions.

RupeeFlow is a unified banking intelligence platform designed to help users understand, organize and monitor their financial activities through a centralized dashboard.

The platform analyzes uploaded bank statements, categorizes transactions, provides financial insights, monitors loan repayment schedules and helps users identify potentially suspicious payment links and UPI QR codes.

## 🎯 Project Objectives

- Simplify bank statement management.
- Automatically categorize financial transactions.
- Track income, expenses and transfers.
- Provide financial analytics and visual reports.
- Monitor loan repayments and upcoming payment dates.
- Identify potentially suspicious URLs and UPI QR codes.
- Provide an integrated financial assistant.
- Improve financial awareness and transaction security.

## 🏗️ System Architecture

RupeeFlow follows a modular application architecture.

1. User Interface Layer – Provides the dashboard and application modules.
2. Application Logic Layer – Handles transaction processing, categorization, analytics and application workflows.
3. Database Layer – Stores application data using Supabase and PostgreSQL.
4. Security Layer – Supports authentication and financial security analysis.

## 🚀 Installation and Setup

### Prerequisites
- Node.js
- npm
- Visual Studio Code
- Supabase project configuration

### Step 1: Clone the repository

```bash
git clone https://github.com/deepth21217-eng/RupeeFlow.git
```

### Step 2: Open the project

```bash
cd RupeeFlow
```

### Step 3: Install dependencies

```bash
npm install
```

### Step 4: Configure environment variables

Create a `.env` file in the project root and add the Supabase credentials using the variable names required by the project.

Never upload secret keys or passwords to GitHub.

### Step 5: Start the application

```bash
npm run dev
```

Open the local URL displayed in the terminal.
